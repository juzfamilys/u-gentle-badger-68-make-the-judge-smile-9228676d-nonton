## The line

> This morning the warung auntie slipped an extra krupuk into my bag, whispering 'for the cat' — and Oyen crunched it on the porch like a food critic giving five stars.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validates it against the 1–200 character gate, and reads it back to confirm what landed on disk.
